# Welcome to the **Illu Engine** wiki!

## What is **Illu Engine**?
**Illu engine** is a project meant to make development of games using pygame easier

## How to install it?
In order to install **Illu Engine** you need to install **python** first, click [here](https://www.python.org/downloads/) to get to python's page and download the latest release

Next you'll need to install **pygame** (pygame-ce should work), to install it click [here](https://www.pygame.org/wiki/GettingStarted) for guide

Next you'll need to download **Illu** itself, click [here](download-and-installation.md) and follow the download guide on the site

## How to update?
When you wnat to update to a newer version you should only copy in the **Illusion package** from the zip file.
If you want to update files outside it you should first read trough the differences between your version and the version you want to update to.

Degrading versions isn't adivced as it will most probably not work.
