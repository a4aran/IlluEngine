# Download

In order to download **Illu** you'll need to download [latest release](https://github.com/a4aran/IllusionEngine/releases/latest).

Latest release might not be the latest version of the engine. If you want to use the latest version go to the [main page](https://github.com/a4aran/IlluEngine), make sure you're on the master branch and click the _CODE_ button and select download zip.

No matter which method you select the result will be a **zip** file.

# Installation

After downloading the **zip** file create a folder where you want to make your game. Next extract/unpack the file and put the content inside your game's folder.

After adding the engine into your project folder you can run `python -m run.py` in the terminal from the root directory.

# Updating

Updating the `su` versions of the engine works by pasting the newer version into the project folder.
Advised to only update the **Illusion package**. Other files can be safely updated after your revision.
