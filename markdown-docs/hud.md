Head-up Display (**GUI**)

In **Illu** HUD elements/objects are those that user can't interact with, but can get information from like [Text Display](hud-elements/text-display.md).

GUI Elements:
- [Image](?load=hud-elements/image.md)
- [Animation](?load=hud-elements/animation.md)
- [Parallax](?load=hud-elements/parallax.md)
- [Text Display](?load=hud-elements/text-display.md)
- [Formatted Text Display](?load=hud-elements/formatted-text-display.md)
