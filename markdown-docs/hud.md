Subclass of [UI](?load=ui)

Head-up Display (**GUI**)

In **Illu** HUD elements/objects are those that user can't interact with, but can get information from like [Text Display](hud-elements/text-display).

GUI Elements:
- [Image](?load=hud-elements/image)
- [Animation](?load=hud-elements/animation)
- [Parallax](?load=hud-elements/parallax)
- [Text Display](?load=hud-elements/text-display)
- [Formatted Text Display](?load=hud-elements/formatted-text-display)
